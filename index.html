Background

About My
Internship

I'm interning at the EdTech Department of HELP International School as a Software Engineering & IT Support Intern, contributing to a real-world school pickup management system called Elevare.

The system uses Automatic Number Plate Recognition (ANPR) cameras to detect when parents arrive at the school gate, automatically notifying students to proceed to the pickup zone — eliminating the chaotic manual name-calling process at dismissal time.

My role spans mobile app development in React Native, backend integration with Node.js, database management with MySQL, server infrastructure setup, and hands-on IT support — alongside collaborating with A-Level student developers.

06

Personal Growth

Reflections &
Takeaways

01 · Challenges

Obstacles I've
Pushed Through

Joining an already-developed codebase demanded real effort to understand existing structure. SMTP restrictions blocked OTP for days. In Week 4, the backend was tied to a personal laptop causing mystery failures. In Week 5, firewall configuration and port access required coordinating with the network administrator — the app had to be tested across both school WiFi and mobile data before stability was confirmed.

02 · Lessons

What I've
Learned to Do

Read existing code before making changes. When one solution fails, pivot systematically. Production systems depend on server and DNS config, not just correct code. Real-world deployments require stable synchronisation between frontend, backend, and database. Proper documentation — SRS, UML, ERD, DFD — is as important as the code itself.

03 · Pride

What I'm
Proud Of

Proposing and fully implementing OTP from scratch. Successfully deploying the ANPR backend to the school's production server in Week 5 and making it accessible on the school network. Adding unregistered vehicle monitoring as a proactive new feature. Being trusted with a brand-new system (Lost & Found) to design from the ground up.

04 · Ahead

What's
Coming Next

Continuing Lost & Found System development — Figma UI design, then moving into actual implementation. Testing the ANPR system on more devices and networks. Further improving app stability and completing the APK for distribution. Updating and maintaining the vehicle registration database on an ongoing basis.
